# 前端工作区统一修复

本次针对前次交付中遗留的双页面框架及相关交互问题修复。代码直接修改在原 App 仓库，当前本地地址仍为 http://127.0.0.1:19173/sandbox 。未改动 WARDEN/AgentGuard 的实验实现，没有提交新模型任务，也没有推送或部署。

## 根因与主要修复

原先五个实验页面各自渲染深色侧栏和顶栏，项目、报告、调查、系统页面则挂在旧的白色 AppLayout 下。路由跳转会切换整个框架，导航名称、登录区和页面状态也不一致。

现在所有现有路由都挂在唯一的 WorkspaceLayout 下；原 AppLayout 仅保留兼容导出。全部页面共用品牌、侧栏、顶栏、登录状态、主题变量和窄屏导航。新增测试会在实际点击导航后检查同一个布局 DOM 仍保持挂载，避免以后再次分裂成两套页面。

## 其他一起修正的问题

- 统一表格、卡片、按钮、输入框、状态标签、错误面板及旧交互图谱的深色主题，并修正主题透明度和边框颜色。
- 项目管理新增进入该项目研究与实验的入口；报告/证据页增加研究结果、调查报告、调查证据、多轮报告之间的分区导航；系统页以服务诊断为主，历史统计折叠保留。
- 管理页跳转后回到实验台，保留已选项目、Study、Run 和 Demo 状态；首次自动选择会固定到 URL，避免后台查询刷新时选中记录漂移。
- 证据、报告、防御、发现、假设页面移除默认示例编号，改为明确读取已有记录；URL、刷新、后退/前进保持选择一致，未选择时不发出对应记录查询。
- 修正读取中显示为空列表、缺少项目/Study 错误处理、失败记录仍显示正常颜色，以及当前干预方法未跟随已选实验臂的问题。
- Demo 研究页面不能展开真实登记表单，也不显示缓存的真实运行列表；未选项目时也不能进入另一项目的登记表单。
- 研究高级配置与外层选择同步，内部标题改为二级标题；浏览器页签标题按当前页面统一更新。
- 手机导航与检视器支持 Escape 关闭、键盘焦点恢复/限制和滚动锁定；导航后聚焦正文，避免停在关闭的菜单中。
- 修正长编号和诊断原因在窄屏溢出，补齐找不到页面和页面异常时的统一框架内回退。
