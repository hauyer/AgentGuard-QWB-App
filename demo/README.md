# demo 目录

离线演示数据规划（阶段 B7 交付，本阶段仅定义合同）。

- `fixtures/`：固定样例，每条记录必须包含：
  fixture ID、数据模式（recorded/synthetic）、来源、采集或生成日期、
  原始 AgentGuard 版本、关联 commit、是否脱敏、SHA-256、包含的能力、
  不能用于证明的结论。
- `manifests/`：演示场景清单与回放步骤定义。
- `scripts/`：生成/校验/脱敏演示数据的脚本。

安全约束：不记录真实 API Key、不包含个人隐私与秘密、不包含未授权的真实生产
数据；Demo 数据不得进入 AgentGuard 经验奖励库，不得用于真实因果实验统计；
录制模式不得执行虚假的提交或审批操作。B0 阶段暂无演示数据，禁止在界面展示
未标识的假统计值。
